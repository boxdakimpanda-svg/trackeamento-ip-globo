# Dados cartográficos

As divisões estaduais simplificadas de Brasil e Estados Unidos foram derivadas dos arquivos públicos do projeto [Click That 'Hood](https://github.com/codeforgermany/click_that_hood), distribuído sob licença MIT por Code for America e colaboradores.

Os limites de países vêm do pacote `world-atlas`, gerado a partir do Natural Earth e distribuído como domínio público/ISC conforme o pacote original.

Os arquivos foram simplificados para visualização web. Não devem ser usados como limites jurídicos ou para navegação.
